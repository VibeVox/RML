# RML Utilities
The purpose of this is to facilitate RML (Rematch League) in continuous, smooth growth, and to ensure that everything within the league is presented in the most efficient, user-friendly way possible. This project is planned to have three main parts: the Discord bot, the website, and the database, all of which will be tied to each other and work in tandem.
